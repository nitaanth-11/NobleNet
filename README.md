# NobleNet Software Technologies — Official Website

Multi-page web platform for **NobleNet Software Technologies**, built with **React**, **TypeScript**, **Tailwind CSS**, **Lenis smooth scroll**, and **Three.js** interactive 3D technical scenes.

## Pages

- **Home (`index.html`)** — Full-bleed 3D Silicon Microprocessor & PCB hero, 3D NobleNet logo sculpture in **About Us**, 4 interactive 3D technical architecture models in **Services**, **SentinelAI** gateway, client preview strip, and direct contact info.
- **Products — SentinelAI (`products.html`)** — Official documentation, CLI command reference, scanner tiers, and Python library guide for [`nitaanth-sentinelai`](https://pypi.org/project/nitaanth-sentinelai/), paired with a 3D multi-scanner topology & radar visualization.
- **What Clients Say (`clients.html`)** — Full-width client testimonials featuring **Adv. Jyoti**, **Entrust Legal Services**, **Maison Momento**, and **Emerald Green Environment Trust**.

## Local Development

```bash
npm install

```

## Production Build
